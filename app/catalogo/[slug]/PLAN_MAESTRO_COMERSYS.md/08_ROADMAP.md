# Objetivo general

Construir una plataforma completa para que cada empresa pueda:

- Administrar sus productos.
- Publicar un catálogo digital.
- Recibir pedidos.
- Gestionar clientes.
- Controlar stock.
- Registrar ventas, gastos y ganancias.
- Analizar el funcionamiento del negocio.
- Automatizar tareas con inteligencia artificial.

La filosofía principal de ComerSys es:

> Complejo por dentro. Simple por fuera.

El sistema debe realizar automáticamente el trabajo pesado, mientras el comerciante conserva el control de las decisiones importantes.

# 🧪 Programa piloto

## Objetivo

Probar ComerSys con entre 4 y 5 negocios reales durante 30 días.

## Condiciones

- Uso gratuito durante un mes.
- Configuración inicial sin costo.
- Soporte directo.
- Registro de errores y sugerencias.
- Reunión de evaluación al finalizar la prueba.

## Negocios recomendados

- [ ] Comercio de mates.
- [ ] Indumentaria.
- [ ] Gastronomía.
- [ ] Ferretería.
- [ ] Cosmética u otro rubro.

## Criterios para lanzar la versión 1.0

- [ ] Sin errores críticos.
- [ ] Flujo de pedidos estable.
- [ ] Información separada correctamente por empresa.
- [ ] Experiencia correcta en celular.
- [ ] Copias de seguridad.
- [ ] Seguridad revisada.
- [ ] Opiniones positivas del grupo piloto.
- [ ] Comercios dispuestos a continuar usando el sistema.

# Principios obligatorios

Cada nueva función deberá:

1. Ahorrar tiempo al comerciante.
2. Reducir errores.
3. Ser fácil de entender.
4. Funcionar correctamente en celular.
5. Integrarse con el resto del sistema.
6. Evitar cargar dos veces la misma información.
7. Mantener las decisiones importantes bajo control del dueño.
8. Estar preparada para trabajar con múltiples empresas.

---

# Regla sobre inteligencia artificial

> La IA ayuda, propone y automatiza.  
> El dueño revisa, decide y confirma.

La IA nunca publicará automáticamente:

- Precios.
- Stock.
- Descuentos.
- Promociones.
- Gastos.
- Movimientos financieros.

sin una confirmación explícita del usuario.
